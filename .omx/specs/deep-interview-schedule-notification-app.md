## 의도

종이 다이어리를 열어보지 않으면 일정을 잊는 문제를, 정해진 시각의 휴대폰 알림과 완료 추적으로 해결한다.

## 원하는 결과

안드로이드 월간 달력에서 일정과 할 일을 구분해 입력·수정·삭제한다. 일정은 시간 계획으로 표시하고, 할 일은 직접 완료 체크한다. 오전에는 당일 일정과 할 일을 확인하고 밤에는 미완료 할 일을 다시 확인한다.

## 범위

- 일요일부터 시작하며 일요일은 빨간색, 토요일은 파란색인 월간 달력
- 오늘보다 이전 날짜의 숫자에는 대각선을 표시
- 월간 달력 칸에는 빠른 기간이 아닌 `일정`의 내용만 표시하고 시간은 표시하지 않음
- 연속 일정은 같은 주 안에서 날짜별로 나누지 않고 하나의 가로 바로 표시
- `할 일`과 빠른 기간 항목은 월간 달력 칸에 표시하지 않음
- 선택한 날짜의 일정·할 일 리스트
- 일정과 할 일을 구분해 추가·수정·삭제
- 일정·할 일의 시작·끝 시간은 선택 사항
- 시작 시간을 설정하면 끝 시간을 자동으로 1시간 뒤로 설정하되, 사용자가 끝 시간을 직접 바꾼 뒤에는 유지
- 시작 시간이 빠른 순으로 자동 정렬하며 기존 무시간 항목은 뒤에서 가나다순으로 정렬
- 단일 날짜 또는 시작일·종료일 범위로 일정 등록
- 일정 시작일을 기준으로 `1주일` 또는 `한 달` 기간을 빠르게 설정
- 빠른 기간으로 만든 할 일은 목록과 알림에서 별도 기간 문구를 표시하지 않음
- 빠른 날짜에서 요일을 선택하면 해당 요일의 가장 가까운 날짜에 단일 날짜 일정으로 설정
- 여행·장기 출장처럼 여러 날짜에 걸친 일정을 각 날짜에 표시
- 기간이 겹치는 일정은 서로 다른 색으로 자동 표시
- 같은 일정은 전체 기간에 같은 색을 유지하고 서로 다른 일정은 다른 색으로 표시
- 일정과 할 일의 굵은 제목 및 수동 완료 체크
- 미완료 할 일은 다음 날로 자동 이동하지 않고 원래 날짜에 유지
- `알림 1`(기본 오전 7시): 당일 일정·할 일 전체 리스트
- `알림 2`(기본 오후 11시): 당일 미완료 할 일 리스트
- 당일 할 일이 모두 완료된 경우 오후 알림에 `오늘 할 일 완료` 표시
- 알림에서 월간 목표와 해당 일정 목록을 생략 없이 모두 표시
- 앱 설정에서 오전·오후 알림 시각 변경
- 월간 목표 생성·수정·삭제
- 현재 월간 목표를 일정과 구분되는 별도 색상으로 달력 상단에 표시
- 오전·오후 알림에 현재 월간 목표를 함께 표시
- TimeBlocks를 참고한 가독성 높은 월간 그리드, 색상 일정 블록, 빠른 입력 흐름

## 결정 경계

Codex가 별도 확인 없이 결정할 수 있는 항목:

- 최소 안드로이드 기술 스택과 로컬 저장 방식
- 화면 간 이동, 여백, 타이포그래피 등 세부 UI
- 데이터 모델과 내부 모듈 구성
- 테스트 구조와 빌드 설정

사용자가 앱에서 직접 결정·변경하는 항목:

- 오전·오후 알림 시각
- 일정·할 일 구분, 내용, 날짜, 시작·끝 시간, 완료 상태
- 월간 목표

다시 확인해야 하는 변경:

- 알림의 의미나 기본 동작 변경
- 계정, 동기화, 공유, 외부 연동 추가
- 목표의 표시 위치나 기간 규칙 변경

## 제약

- 안드로이드 전용 개인용 앱
- 서버 없이 기기 로컬 데이터로 동작
- 네트워크 연결 없이 핵심 기능 사용 가능
- 앱 삭제 또는 앱 데이터 삭제 시 모든 일정·목표·설정이 영구 삭제됨
- TimeBlocks의 정보 구조와 사용 감각만 참고하며 화면을 그대로 복제하지 않음
- 한국 시간대를 기본으로 하되 기기의 현재 시간대를 사용

## 검증 가능한 인수 조건

1. 월간 달력은 일요일부터 시작하고 일요일은 빨간색, 토요일은 파란색으로 표시된다.
2. 오늘보다 이전 날짜의 숫자에는 대각선이 표시된다.
3. 월간 달력 칸에는 빠른 기간이 아닌 일정의 내용만 표시되고 시간은 표시하지 않으며, 연속 일정은 같은 주 안에서 하나의 가로 바로 표시된다. 할 일과 빠른 기간 항목은 선택 날짜의 목록에서만 표시된다.
4. 사용자는 항목을 일정 또는 할 일로 구분해 추가·수정·삭제할 수 있다.
5. 일정 생성·편집 시 시작일과 종료일을 지정할 수 있고, 범위의 모든 날짜에 일정이 표시된다.
6. `1주일`을 선택하면 종료일은 시작일을 포함한 7일째, `한 달`을 선택하면 시작일로부터 한 달 전날로 자동 설정된다.
7. 요일 바로가기를 선택하면 시작일 이후 가장 가까운 해당 요일로 시작일과 종료일이 같게 설정된다.
8. 빠른 기간으로 만든 할 일은 목록과 알림에서 기간 문구를 표시하지 않는다.
9. 같은 일정은 전체 기간에 같은 색을 유지하고 서로 다른 일정은 다른 색으로 표시된다.
10. 선택한 날짜의 모든 일정과 할 일이 구분된 리스트로 표시된다.
11. 시간은 선택 사항이며 시작 시간을 설정하면 끝 시간이 1시간 뒤로 자동 설정된다. 사용자가 끝 시간을 직접 변경한 뒤 시작 시간을 바꾸면 끝 시간은 변경되지 않는다. 목록과 알림은 시작 시간이 빠른 순이고 무시간 항목은 뒤에서 가나다순이다.
12. 일정과 할 일 제목은 굵게 표시되며 사용자는 둘 다 직접 완료 또는 미완료로 바꿀 수 있다.
13. 미완료 할 일은 날짜가 지나도 원래 날짜에 남으며 자동 이동하지 않는다.
14. `알림 1`의 기본 시각은 오전 7시이며 해당 날짜의 일정과 할 일을 리스트로 표시한다.
15. `알림 2`의 기본 시각은 오후 11시이며 해당 날짜의 미완료 할 일만 표시한다.
16. 알림 2 발송 시 미완료 일정이 없으면 `오늘 할 일 완료`를 표시한다.
17. 알림에는 월간 목표와 해당 일정이 개수 제한 없이 모두 포함된다.
18. 사용자가 앱에서 두 알림 시각을 변경하면 다음 알림부터 변경값이 적용된다.
19. 사용자는 월간 목표를 만들고 수정하거나 삭제할 수 있다.
20. 해당 월의 목표가 일정과 다른 색으로 달력 상단과 알림 1·알림 2에 표시된다.
21. 앱을 종료했다 다시 열어도 일정·할 일 구분, 기간, 시작·끝 시간, 완료 상태, 월간 목표, 알림 설정이 유지된다.
22. 앱을 삭제하거나 앱 데이터를 삭제한 뒤에는 기존 데이터가 복구되지 않는다.

## 가정과 남은 위험

- 첫 버전은 로컬 단일 기기 사용으로 한정한다.
- 일정이 없는 오전 알림의 문구는 구현 단계에서 간단한 빈 상태 문구로 결정할 수 있다.
- 알림 UI가 접혀 있을 때는 시스템이 요약 문구를 표시할 수 있지만, 펼친 알림 데이터에서는 항목을 코드로 제외하지 않는다.
- 안드로이드 버전별 알림 권한과 절전 정책 때문에 실제 발송 시각에 소폭 지연이 생길 수 있으므로 구현 계획에서 검증해야 한다.
- `TimeBlocks처럼`은 월간 가독성, 색상 블록, 빠른 입력을 뜻한다. 픽셀 단위 복제는 범위 밖이다.

## 근거와 용어

- 저장소는 코드·문서가 없는 신규 프로젝트다.
- `일정`과 `할 일`은 표시 위치와 알림 역할이 다르지만 둘 다 사용자가 직접 완료 체크할 수 있다.
- `목표`는 해당 월에 표시할 짧은 문구이며, 주간 목표와 달성률을 제공하지 않는다.
- TimeBlocks 공식 소개는 가독성 높은 월간 캘린더, 캘린더 내 빠른 입력, 간단한 편집을 핵심 경험으로 설명한다: https://www.timeblocks.com/

## 압박 검증

- 고정 알림이라는 초기 답을 실제 날짜 시나리오로 재검토해 오전/오후의 서로 다른 역할을 확정했다.
- 후속 사용자 요청에 따라 일정과 할 일을 별도 유형으로 분리했다.
- 후속 사용자 요청에 따라 목표와 할 일의 연결 및 달성률 계산을 제거하고, 월간 목표만 달력 상단과 알림에 표시하도록 변경했다.
